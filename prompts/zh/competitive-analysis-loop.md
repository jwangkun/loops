# 竞品分析循环

**分类:** 运营与市场  
**标识符:** `competitive-analysis-loop`  
**最大迭代次数:** 10

## 目标
产出一份结构完整、每条结论都可溯源的竞品分析报告，并通过 `competitor_check.py` 的全部校验。成功意味着报告包含所有必需章节，且每个数据点都附有可访问的原始来源链接及采集日期。

## 适用场景
进入新市场、规划产品路线、定价调整或营销策略制定前，需要一份可信、可引用的竞品基线时使用。

## 检查命令

```bash
python scripts/competitor_check.py
```

## 退出条件
- 检查命令以退出码 0 通过。
- 所有必需章节齐全（概览、定位、功能对比、定价、优势/劣势、结论）。
- 每条数据点均有有效来源链接，且来源在采集日期内仍然可访问。

## 执行步骤
Step 1: 运行 `python scripts/competitor_check.py`，完整捕获输出与退出码。
Step 2: 分析失败项，区分三类缺口：缺失章节、缺失/失效来源、数据陈旧；针对每个缺口定位报告中的对应位置。
Step 3: 做最小补充：补齐缺失章节、为无来源结论补充可访问的原始链接与采集日期；不得编造数据或用二手转述冒充一手来源。
Step 4: 重新运行检查命令；若仍有失败且未达最大迭代次数，回到 Step 2。
Step 5: 若已达最大迭代次数仍未通过，停止并报告剩余缺口（章节、来源、陈旧数据），不要无限循环。

## 常见陷阱
- 使用陈旧数据（如上季度定价、已下线功能），未核对采集日期。
- 把相关性误当成战略结论（如"竞品 X 涨价了我们也要涨"），缺乏因果依据。
- 引用二手聚合站而非原始来源，导致来源不可核验或被聚合站改写。
- 只看头部竞品，忽视细分领域新进入者或替代品。

## 注意事项
- 每条结论都必须可溯源；无法核实的观点要标注为推断而非事实。
- 来源要注明采集日期，并在迭代中复查链接是否仍可访问。
- 保持客观，避免为预设结论挑选数据（cherry-picking）。
