# 设计Token同步

**分类:** 前端与UI  
**标识符:** `design-token-sync`  
**最大迭代次数:** 8

## 目标

所有UI使用批准的设计token

## 检查命令

```bash
npm run lint:design-tokens
```

## 执行步骤

Step 1: 扫描硬编码值。替换为设计token。重复。
