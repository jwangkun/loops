# 邮件营销循环

**分类:** 运营与市场  
**标识符:** `email-campaign-loop`  
**最大迭代次数:** 5

## 目标
让邮件营销活动通过 `email_check.py` 的全部审查，覆盖主题行、正文内容、链接有效性、图片与合规性。成功意味着检查命令零失败项退出，活动可安全投递。

## 适用场景
新建或修改邮件模板、A/B 测试变体、促销或生命周期邮件上线前，用本循环确保内容、链接与合规基线达标。

## 检查命令

```bash
python scripts/email_check.py
```

## 退出条件
- 检查命令以退出码 0 通过，且无 error。
- 主题行、正文、全部链接（含退订链接）可达且有效，图片有 alt 文本，合规项（退订、发件人信息）齐全。

## 执行步骤
Step 1: 运行 `python scripts/email_check.py`，完整捕获输出与退出码，记录每条失败的模块（主题/正文/链接/图片/合规）。
Step 2: 分析失败项并归类：主题过长或触发垃圾词、链接断裂或过期、图片缺 alt 或体积过大、缺失退订/发件人信息、单张超大图片正文等；定位到具体模板片段。
Step 3: 做最小修复：改正单个字段或链接，为图片补 alt 并控制体积，确保退订链接存在且可达；不得为通过检查而删除退订或用图片替代文本正文。
Step 4: 重新运行检查命令；若仍有失败且未达最大迭代次数，回到 Step 2。
Step 5: 若已达最大迭代次数仍未通过，停止并报告剩余失败项（模块、原因、建议），不要无限循环。

## 常见陷阱
- 整封邮件用一张超大图片承载正文，触发图片拦截后内容为空且影响投递。
- 图片缺少 alt 文本，图片被屏蔽时收件人看不到任何信息。
- 主题行使用全大写或垃圾触发词（如"免费""限时"），显著降低到达率。
- 退订链接缺失或埋藏过深，违反合规并拉高投诉率。
- 链接仅在桌面浏览器验证，忽视邮件客户端预取导致点击统计失真。

## 注意事项
- 不得为通过检查而移除或弱化退订机制与发件人身份信息。
- 链接修复须指向真实可达的目标，禁止用占位符或 301 跳转掩盖失效。
- 保持内容与落地页一致，避免标题/正文与目标页承诺不符。
