# 闪卡生成器

**分类:** 学习与知识管理
**标识符:** `flashcard-generator`
**最大迭代次数:** 20

## 目标

为指定学习材料中的每一个关键概念生成简明、可自测的问答闪卡。每张闪卡问题清晰、答案自洽，独立考查单一原子化概念，并要求主动回忆而非被动识别。

## 适用场景

需要把文档、讲义或笔记转化为可间隔重复复习的闪卡集时使用。

## 检查命令

```bash
python scripts/flashcard_check.py
```

## 退出条件

- 检查脚本退出码为 0。
- 提取出的每个概念至少拥有一张闪卡。
- 无重复卡、无空答案、无占位符。

## 执行步骤

Step 1: 运行检查命令，捕获缺失概念的清单与质量告警。
Step 2: 逐项分析缺口：哪些概念无卡、哪些卡只考 yes/no、哪些卡塞入多个概念、哪些问题已透露答案。
Step 3: 做最小修改：为缺失概念补一张原子化问答卡，重写琐碎或诱导式问题；不删除有效卡，不堆砌冗余。
Step 4: 重新运行检查；若仍失败且未达最大迭代次数，回到 Step 2。
Step 5: 达到最大迭代仍未通过，停止并报告剩余未覆盖概念或质量问题，绝不无限循环。

## 常见陷阱

- 制造只需 yes/no 的琐碎问题，无法触发主动回忆。
- 一张卡塞入多个概念，答案含糊无法自测。
- 问题本身透露答案（诱导式提问）。
- 复制原文大段而非压缩为原子化知识点。

## 注意事项

- 闪卡必须基于原始材料，禁止编造材料中没有的事实。
- 每张卡只考一个原子化概念。
- 答案须可回溯到来源位置，便于核对。

- 收敛保护：若同一检查以相同根因连续两次迭代失败，应更换思路或停止上报，而非机械地原样重试。
- 预算纪律：遵守宿主 harness 的 token / 成本 / 时间预算；预算耗尽视为「停止并上报」信号，而非重试信号。
- 终态明确：循环只能以「成功 / 受阻 / 耗尽」三种终态结束；停滞或预算耗尽绝不能被报告为成功。
