# 笔记整理器

**分类:** 学习与知识管理
**标识符:** `note-organizer`
**最大迭代次数:** 20

## 目标

为每一条笔记补充一致的标签、双向链接与清晰标题结构，使其可被高效检索与关联。标签体系一致，链接指向真实存在的笔记，层级与原文意图匹配。

## 适用场景

当笔记库杂乱、缺标签或缺链接，难以跨笔记建立关联时使用。

## 检查命令

```bash
python scripts/note_check.py
```

## 退出条件

- 检查脚本退出码为 0。
- 所有笔记已加标签并完成链接。
- 无断链、无重复近义标签。
- 非孤立笔记均至少存在一条关联。

## 执行步骤

Step 1: 运行检查命令，捕获断链、缺标签与孤立笔记清单。
Step 2: 分类问题：标题引用指向不存在的目标、单方向未补反向链接、近义重复标签、本应关联却孤立的笔记。
Step 3: 做最小修改：沿既有标签命名约定补标签、补全双向链接、合并近义标签、修复因改标题产生的断链；不为建链接而新建空占位笔记。
Step 4: 重新运行检查；若仍失败且未达最大迭代次数，回到 Step 2。
Step 5: 达到最大迭代仍未通过，停止并报告剩余阻塞项（如循环引用、命名冲突），绝不无限循环。

## 常见陷阱

- 过度打标签，制造大量只出现一次的近义标签。
- 双向链接只建单方向，导致关联断裂。
- 改动标题却未更新引用它的链接。
- 把结构强加于本应是流水账的笔记。

## 注意事项

- 标签须沿用既有命名约定，不擅自新增近义词。
- 链接目标必须真实存在，禁止创建空占位笔记。
- 保留原文含义，不重写到失真。

## 推荐代理

Claude Code、Cursor、Trae、Windsurf、Cline
