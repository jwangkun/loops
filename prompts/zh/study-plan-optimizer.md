# 学习计划优化器

**分类:** 学习与知识管理
**标识符:** `study-plan-optimizer`
**最大迭代次数:** 5

## 目标

使学习计划在给定时间预算内现实可行，并完整覆盖全部目标主题。每日/每周任务量与实际可用时间匹配，难度递进合理，并为复习与缓冲预留余量。

## 适用场景

当现有学习计划出现过载、主题遗漏或时间分配不当时使用。

## 检查命令

```bash
python scripts/study_plan_check.py
```

## 退出条件

- 检查脚本退出码为 0。
- 计划覆盖所有必选主题。
- 总用时不超过可用时间预算。
- 每日负荷均衡，无空日程或超载日。

## 执行步骤

Step 1: 运行检查命令，捕获覆盖缺口、超载项与不平衡项的清单。
Step 2: 定位问题根因：哪些主题未排、哪些日程超出当日可用时间、哪些主题依赖顺序错误、是否缺少复习与缓冲。
Step 3: 做最小调整：迁移超载任务到有余量的日子、补齐缺失主题、保留复习与缓冲；不重排已合理的部分。
Step 4: 重新运行检查；若仍失败且未达最大迭代次数，回到 Step 2。
Step 5: 达到最大迭代仍未通过，停止并报告剩余阻塞项（如总预算不足、主题互相冲突），绝不无限循环。

## 常见陷阱

- 高估每日可投入时长，使计划必然失败。
- 堆砌主题却忽略复习与休息的缓冲时间。
- 忽略主题间依赖（先练进阶后补基础）。
- 把日程精确到分钟，失去应对意外的弹性。

## 注意事项

- 以提供的真实可用时间预算为准，不得虚构学习时长。
- 始终为复习与意外保留缓冲，不要把日程填满到 100%。
- 主题顺序须尊重依赖关系。
