# 任务优先级排序器

**分类:** 效率与生产力
**标识符:** `task-prioritizer`
**最大迭代次数:** 20

## 目标

为待办清单中的每个任务赋予影响力评分、工作量估算及由此推导的优先级，使列表顶端任务明确无歧义，校验脚本通过。成功意味着任何人看清单都能立刻知道下一步该做什么。

## 适用场景

在任务清单/待办积压需要排序、准备进入冲刺或日计划前使用。

## 检查命令

```bash
python scripts/task_check.py
```

## 退出条件

- 所有任务都有影响力评分、工作量估算和优先级。
- 列表按优先级排序，顶端任务明确无并列歧义。
- 每个评分可追溯到依据（关联目标/拆解依据）。

## 执行步骤

Step 1: 运行 `python scripts/task_check.py`，捕获缺评分、缺估算或优先级未决的任务列表。
Step 2: 取一个未完成任务，分析其影响力（对哪个目标贡献多大）与工作量（基于拆解而非凭空猜测），并确认是否有并列优先级需要打破。
Step 3: 做最小修复：填入影响力与工作量、计算优先级、必要时调整排序打破并列，绝不靠给所有任务同分来回避取舍。
Step 4: 重新运行校验；若仍有未决任务且未达最大迭代次数，回到 Step 2。
Step 5: 若达到最大迭代次数仍未通过，停止并报告剩余阻塞项（如任务信息不足、无法估算），不要无限循环。

## 常见陷阱

- 不做任何拆解就凭感觉估算工作量，数字不可信。
- 影响力评分脱离具体目标，变成主观拍脑袋。
- 留下并列优先级不打破，顶端任务仍有歧义。
- 调整排序后未重新计算评分，导致顺序与分数矛盾。

## 注意事项

- 评分必须基于任务的客观信息，不得为凑过校验虚增/虚降。
- 工作量估算应注明单位（小时/人天）与假设前提。
- 高影响力但高工作量的任务，考虑是否拆分后再排。
