# 用户故事生成器

**分类:** 产品与设计  
**标识符:** `user-story-generator`  
**最大迭代次数:** 15

## 目标

为每个功能生成用户故事

## 检查命令

```bash
python scripts/story_check.py
```

## 退出条件

所有功能都有带验收标准的用户故事

## 执行步骤

Step 1: 选择功能。编写带验收标准的用户故事。验证。重复。
