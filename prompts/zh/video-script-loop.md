# 视频脚本循环

**分类:** 内容创作与写作
**标识符:** `video-script-loop`
**最大迭代次数:** 8

## 目标

让视频脚本在目标时长内达到开场钩子有效、叙述清晰、节奏紧凑的可拍摄状态。每一稿都经 `script_review.py` 验证，针对其报告的具体缺陷做最小、有针对性的修改，而非泛泛重写。成功即检查通过且时长落在目标区间。

## 适用场景

在撰写或修订视频脚本（口播、教程、短片解说）时使用，尤其当存在目标时长或留存/完播率指标要求时。

## 检查命令

```bash
python scripts/script_review.py
```

## 退出条件

- `script_review.py` 退出码 0，无未解决问题。
- 脚本总时长落在目标区间内。
- 开场钩子、结构、节奏检查全部通过。

## 执行步骤

Step 1: 运行检查，完整捕获输出（时长偏差、钩子强度、清晰度问题按段落列出）。
Step 2: 逐条分析失败：区分时长超标、钩子失效、信息密度过低或逻辑跳跃；定位到具体段落与原因。
Step 3: 用最小改动修复该段——精简冗余、重写弱钩子、补足缺失过渡——而非整篇重写。
Step 4: 重新运行检查；若仍失败且未达最大迭代次数，回到 Step 2。
Step 5: 达到最大迭代仍未通过则停止，报告剩余阻塞项（段落、问题类型、时长差），不要无限循环。

## 常见陷阱

- 为压时长机械删词，牺牲掉必要信息或逻辑连贯性。
- 开场钩子停留在事实陈述，缺少在前 5 秒制造好奇心或冲突。
- 按字数估算时长而非实际口播节奏，导致真实录制严重超时。
- 只盯单个弱段落，忽视整片节奏曲线（铺垫、高潮、回收）。

## 注意事项

- 保留既定的事实、品牌口径与口播风格，不杜撰数据。
- 时长目标必须由需求方明确给出；未给定时先确认，不要自行假设。
- 修改保持脚本可拍摄，避免书面化长句。
